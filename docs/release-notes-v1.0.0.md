Release v1.0.0

Вебсистема онлайн-замовлень у кав’ярні

Версія 1.0.0 є стабільною версією MVP вебсистеми онлайн-замовлень у кав’ярні. У цій версії реалізовано основний функціонал для клієнта та адміністратора, взаємодію Front-end і Back-end через REST API, роботу з базою даних та адміністративну автентифікацію.

Основні можливості:

Клієнтська частина
- перегляд меню та категорій;
- перегляд інформації про товари;
- додавання товарів до кошика;
- зміна кількості товарів;
- видалення товарів із кошика;
- оформлення попереднього замовлення;
- введення контактних даних;
- вибір доступного часу самовивозу;
- отримання номера замовлення та коду отримання;
- перегляд статусу замовлення;
- відображення орієнтовного часу готовності.

Серверна частина
- REST API на Node.js та Express;
- робота з SQLite через Prisma ORM;
- керування категоріями та товарами;
- створення та обробка замовлень;
- контроль місткості часових слотів;
- перевірка доступності товарів;
- розрахунок загальної вартості замовлення;
- визначення орієнтовного часу готовності;
- керування статусами замовлень.

Адміністративна частина
- вхід адміністратора;
- JWT-автентифікація;
- розмежування доступу до адміністративних операцій;
- перегляд замовлень;
- зміна статусів замовлень;
- керування товарами;
- керування категоріями;
- створення та деактивація часових слотів;
- перегляд поточного навантаження кав’ярні.

Технології

- Git
